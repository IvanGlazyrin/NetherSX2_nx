## 2024-05-23 - Optimizing String Parsing Loops with std::string_view
**Learning:** In C++ parsing routines (like INI config or cheat file parsing), heavily called string manipulation functions like `trim` that take `std::string` by value or const reference still cause widespread intermediate string allocations when called with `.substr()`. Using `std::string_view` for string-based utility functions eliminates all these temporary allocations and noticeably improves parsing efficiency, while keeping changes localized.
**Action:** Always prefer `std::string_view` over `std::string` parameters for string utility/parsing functions when avoiding modifications or ownership. When refactoring legacy `const std::string&` helpers, `std::string_view` is usually a drop-in replacement that instantly avoids temporary memory allocations from inline `.substr()` calls in parsing loops.
