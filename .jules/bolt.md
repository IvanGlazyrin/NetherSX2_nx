## 2024-10-13 - Optimize string parsing loops with std::string_view
**Learning:** Parsing text loops that frequently use substrings for prefix matching or trimming (`trim_copy`, `substr`) will create a large number of temporary string allocations. Using C++17/20 `std::string_view` for read-only tracking of text positions provides an immense performance boost by doing pointer arithmetic rather than allocations. Additionally, when modifying strings like adding or removing comments, mutating a string in-place with `.erase` and `.insert` is substantially faster (1.8x in benchmarks) than allocating substrings and re-appending them via `+` operators.
**Action:** Always prefer `std::string_view` over `const std::string&` for parsing parameters and avoid `substr` allocations unless a discrete string instance is required to outlive the parent. Use in-place `erase` and `insert` for simple toggle logic instead of extracting parts.
