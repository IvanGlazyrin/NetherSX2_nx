## 2024-10-24 - Fast-path return in std::string trim functions
**Learning:** Optimizing `trim` and `Trim` string functions which previously blindly used `std::string::substr`. Even when returning the entire original string, `substr` will perform an allocation and memory copy (unless SSO prevents the allocation itself, which is not guaranteed for larger config values or titles). Adding a simple check to see if `first == 0` and `last == string.size() - 1` allows the function to return the original string or string reference untouched, avoiding allocations in the "clean" path. Testing showed 20-50% speedups.
**Action:** Always check if a substring function is extracting the full string and return the original string early if possible to bypass unnecessary allocations, especially on cold paths that are frequently called like configuration parsing.
