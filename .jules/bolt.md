## 2024-05-18 - Optimize trim string parsing in CheatManager
**Learning:** `std::string::substr` creates a heap allocation for the returned string slice. Even when returning a string via a copying fast-path like `trim_copy`, using `std::string_view` for parsing (`skip_space`) and utilizing `std::string_view::substr` avoids a temporary string creation, which improves parsing performance substantially. We can further optimize it by constructing `std::string_view` from original strings `std::string_view(line).substr(offset)` when doing parsing passes.
**Action:** When implementing or fixing string trimmers and spaces skippers, update their signatures from `const std::string&` to `std::string_view` and use string view subsets, only copy constructing `std::string` objects explicitly at the end boundaries.
